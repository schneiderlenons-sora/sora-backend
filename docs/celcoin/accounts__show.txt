ownload Bruno Collection
GET/accounts/{account}
Obter Conta
Retorna uma conta bancária com identification, balance e overdraft_limit. Rate-limited — não use para polling.
Observações
Rate limit: 30 requisições/minuto por usuário autenticado (ou IP). Ver /docs/celcoin/rate-limits.
Não faça polling nesta rota. O fluxo ideal é orientado a webhooks.
Ao receber um evento de recurso (ex.: accounts, credit_cards), busque pelo index paginado do consentimento com query_parameters (ex.: GET /consents/{consent}/accounts?{query_parameters}).
Ao receber *.transactions, liste as transações do recurso indicado em resource/resource_id com query_parameters.
Use o show apenas pontualmente — quando precisar do recurso completo (reconciliação, debugging, etc.).
Campos de identification (subtype, currency, etc.) estão na raiz. O objeto identification é legado.
identification, balance e overdraft_limit podem ser null se ainda não sincronizados.
Se balance.has_reserved_balance = true, liste as caixinhas em GET /accounts/{account}/reserved-balances.

balanceobject
Saldo da conta. Retornado em listagens e detalhe quando sincronizado. Pode ser null se ainda não sincronizado.
Field Type Description
update_date_time string Data/hora da atualização do saldo.
has_reserved_balance boolean Indica se o cliente possui reserva de saldo (caixinhas). Se true, consulte GET /accounts/{account}/reserved-balances. Inclui reservas ativas mesmo com saldo zerado.
available_amount object Saldo disponível { amount, currency }. Não inclui cheque especial, investimentos automáticos nem reservas de saldo.
blocked_amount object Saldo bloqueado { amount, currency }.
automatically_invested_amount object Saldo investido automaticamente { amount, currency }.
updated_at string Última atualização (ISO 8601).
