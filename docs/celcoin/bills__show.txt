GET/bills/{bill}
Obter Fatura
Retorna uma fatura de cartão de crédito. Rate-limited — não use para polling.
Observações
Rate limit: 30 requisições/minuto por usuário autenticado (ou IP). Ver /docs/celcoin/rate-limits.
Não faça polling nesta rota. O fluxo ideal é orientado a webhooks.
Ao receber um evento de recurso (ex.: accounts, credit_cards), busque pelo index paginado do consentimento com query_parameters (ex.: GET /consents/{consent}/accounts?{query_parameters}).
Ao receber *.transactions, liste as transações do recurso indicado em resource/resource_id com query_parameters.
Use o show apenas pontualmente — quando precisar do recurso completo (reconciliação, debugging, etc.).

payments[]object
Pagamentos registrados na fatura. Um pagamento fica atrelado à fatura que fechar em seguida a ele — inclusive pagamentos avulsos feitos antes do fechamento (ex.: para liberação de limite), que entram na fatura seguinte junto com o pagamento do ciclo. Exceção: pagamento avulso para liberação de limite feito após o fechamento é reportado só na fatura seguinte, quando ela de fato fechar; até lá, aparece apenas em GET /transactions e /transactions-current.
Field Type Description
amount string Valor pago.
currency string Moeda.
paymentDate string Data do pagamento.
valueType string Enum: CreditCardBillingValueType.
paymentMode string Enum: CreditCardPaymentMode.
Exemplo

}
