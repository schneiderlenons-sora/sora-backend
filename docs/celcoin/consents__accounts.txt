GET/consents/{consent}/accounts
Listar Contas do Consentimento
Lista contas bancárias vinculadas ao consentimento, incluindo identificação (identification), saldo (balance) e limite de cheque especial (overdraft_limit) quando sincronizados.
Observações
Quando fromCreatedAt/toCreatedAt e fromUpdatedAt/toUpdatedAt são enviados juntos, a API combina com OR: retorna registros criados OU atualizados na janela (não exige as duas condições ao mesmo tempo).
Campos de identification (subtype, currency, etc.) estão na raiz. O objeto identification é legado.
identification, balance e overdraft_limit são carregados via eager loading e podem ser null se ainda não sincronizados.
Se balance.has_reserved_balance = true, liste as caixinhas em GET /accounts/{account}/reserved-balances.
Query Parameters
Field Type Description
cursor string Cursor de paginação (cursor-based). Use o next_cursor da resposta anterior para avançar. 15 itens por página.
fromCreatedAt string Filtra por created_at a partir desta data (ISO 8601). Opcional.
toCreatedAt string Filtra por created_at até esta data (ISO 8601). Opcional. Deve ser ≥ fromCreatedAt quando ambos forem enviados.
fromUpdatedAt string Filtra por updated_at a partir desta data (ISO 8601). Opcional.
toUpdatedAt string Filtra por updated_at até esta data (ISO 8601). Opcional. Deve ser ≥ fromUpdatedAt quando ambos forem enviados.

balanceobject
Saldo da conta. Retornado em listagens e detalhe quando sincronizado. Pode ser null se ainda não sincronizado.
Field Type Description
update_date_time string Data/hora da atualização do saldo.
has_reserved_balance boolean Indica se o cliente possui reserva de saldo (caixinhas). Se true, consulte GET /accounts/{account}/reserved-balances. Inclui reservas ativas mesmo com saldo zerado.
available_amount object Saldo disponível { amount, currency }. Não inclui cheque especial, investimentos automáticos nem reservas de saldo.
blocked_amount object Saldo bloqueado { amount, currency }.
automatically_invested_amount object Saldo investido automaticamente { amount, currency }.
updated_at string Última atualização (ISO 8601).
