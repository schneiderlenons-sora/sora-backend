GET/consents/{consent}/resources
Listar Recursos do Consentimento
Consulta a Celcoin em tempo real e lista os recursos Open Finance do consentimento. resource_id é o UUID local da Polp — nunca o identificador da Celcoin.
Atenção aos status
TEMPORARILY_UNAVAILABLENão indica erro permanente: o recurso pode voltar a AVAILABLE. Não interprete como encerramento. Implemente retry ou polling antes de comunicar indisponibilidade ao usuário. UNAVAILABLE sim indica encerramento.
PENDING_AUTHORISATIONEm alçadas duplas, para contas com mais de um titular, todos devem autorizar o consentimento. Recursos neste status só transitam para AVAILABLE após todos os co-titulares autorizarem.
AUTHORISEDA rota só funciona para consentimentos neste status (a permission RESOURCES_READ já é solicitada na criação). Tentativas com AWAITING_AUTHORIZATION, REJECTED, EXPIRED ou consentimento revogado retornam erro.
Observações
A cada chamada a Polp consulta a Celcoin em tempo real e devolve o UUID local da Polp em resource_id, quando o recurso já existe na base.
O resourceId da Celcoin não aparece na resposta. Use resource_id nas rotas da Polp (GET /accounts/{id}, GET /credit-cards/{id}, GET /loans/{id}, etc.).
resource_id é null quando o recurso ainda não foi persistido, ou quando o tipo não tem modelo local: EXCHANGE, UNARRANGED_ACCOUNT_OVERDRAFT e INVOICE_FINANCING.
Correspondência por type: ACCOUNT → accounts; CREDIT_CARD_ACCOUNT → credit-cards; LOAN → loans; FINANCING → financings; BANK_FIXED_INCOME → bank-fixed-incomes; CREDIT_FIXED_INCOME → credit-fixed-incomes; VARIABLE_INCOME → variable-incomes; TREASURE_TITLE → treasure-titles; FUND → funds.
Não é paginação por cursor: a resposta é { "data": [ ... ] } com a lista completa.
Response Fields
Field Type Description
type string Tipo do recurso Open Finance. Enum: ResourceType.
type_label string Rótulo traduzido do tipo.
status string Status do recurso na instituição. Enum: ResourceStatus.
status_label string Rótulo traduzido do status.
resource_id string | null UUID local da Polp (conta, cartão, empréstimo, financiamento ou investimento). Nunca é o resourceId da Celcoin. Null se o recurso ainda não foi persistido, ou se o tipo não tem modelo local (EXCHANGE, UNARRANGED_ACCOUNT_OVERDRAFT, INVOICE_FINANCING).
