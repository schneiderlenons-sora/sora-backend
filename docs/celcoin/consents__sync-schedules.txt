GET/consents/{consent}/sync-schedules
Cronograma de Sincronização
Retorna o cronograma de sincronização de recursos do consentimento — listagens, identificação de produto, saldos e transações por recurso.
Observações
Recursos de investimento incluem *.product (Product Identification), *.balances e *.transactions por investmentId.
Contas e cartões incluem *.identification (Account Identification / Credit Card Identification) por accountId ou creditCardAccountId.
Empréstimos incluem loan.contract (Contract Identification) por contractId.
resource_id contém o ID do recurso sincronizado (conta, cartão, investimento, etc.) quando aplicável.
A faixa e o intervalo de cada resource seguem o plano — veja Frequência de Atualização na documentação.
Query Parameters
Field Type Description
cursor string Cursor de paginação (cursor-based). Use o next_cursor da resposta anterior para avançar. 50 itens por página.
Response Fields
Field Type Description
consent_id string ID do consentimento.
resource string Recurso sincronizado. Enum: ConsentSyncResource.
resource_id string | null ID do recurso sincronizado (conta, cartão, investmentId, etc.), quando aplicável. Usado em recursos por instância (*.balances, *.transactions, *.product).
last_sync_at string | null Última sincronização (ISO 8601).
next_sync_at string | null Próxima sincronização agendada (ISO 8601).
