ownload Bruno Collection
GET/credit-cards/{creditCard}/bills
Listar Faturas do Cartão
Lista faturas de um cartão de crédito.
Observações
Quando fromCreatedAt/toCreatedAt e fromUpdatedAt/toUpdatedAt são enviados juntos, a API combina com OR: retorna registros criados OU atualizados na janela (não exige as duas condições ao mesmo tempo).
Query Parameters
Field Type Description
cursor string Cursor de paginação (cursor-based). Use o next_cursor da resposta anterior para avançar. 15 itens por página.
fromCreatedAt string Filtra por created_at a partir desta data (ISO 8601). Opcional.
toCreatedAt string Filtra por created_at até esta data (ISO 8601). Opcional. Deve ser ≥ fromCreatedAt quando ambos forem enviados.
fromUpdatedAt string Filtra por updated_at a partir desta data (ISO 8601). Opcional.
toUpdatedAt string Filtra por updated_at até esta data (ISO 8601). Opcional. Deve ser ≥ fromUpdatedAt quando ambos forem enviados.
Response Fields
Field Type Description
id string Identificador único da fatura.
credit_card_id string ID do cartão.
due_date string Data de vencimento.
bill_closing_date string Data de fechamento da fatura.
is_instalment boolean Indica se a fatura possui parcelamento.
bill_minimum_amount object Valor mínimo { amount, currency }.
bill_total_amount object Valor total { amount, currency }.
payments array Pagamentos realizados. Ver seção Objetos Aninhados → payments[].
finance_charges array Encargos financeiros. Ver seção Objetos Aninhados → finance_charges[].
created_at string Data de criação (ISO 8601).
updated_at string Data de atualização (ISO 8601).
Objetos Aninhados
Estrutura completa dos objetos referenciados nos campos acima. Valores monetários usam o tipo compartilhado { amount, currency }.
amountobject
Tipo compartilhado para valores monetários em toda a API.
Field Type Description

currency string Código ISO 4217 (ex.: "BRL").
Exemplo
TransactionAmountCOPY

"amount": "1500.00",

payments[]object
Pagamentos registrados na fatura. Um pagamento fica atrelado à fatura que fechar em seguida a ele — inclusive pagamentos avulsos feitos antes do fechamento (ex.: para liberação de limite), que entram na fatura seguinte junto com o pagamento do ciclo. Exceção: pagamento avulso para liberação de limite feito após o fechamento é reportado só na fatura seguinte, quando ela de fato fechar; até lá, aparece apenas em GET /transactions e /transactions-current.
Field Type Description
amount string Valor pago.
currency string Moeda.
paymentDate string Data do pagamento.
valueType string Enum: CreditCardBillingValueType.
paymentMode string Enum: CreditCardPaymentMode.
Exemplo
payments[]COPY
{
"amount": "1500.00",
"currency": "BRL",
"paymentDate": "2024-04-10",
"valueType": "VALOR_PAGAMENTO_FATURA_REALIZADO",
"paymentMode": "PIX"
}
finance_charges[]object
Encargos financeiros da fatura.
