GET/credit-cards/{creditCard}/installments
Parcelamentos do Cartão
Lista compras parceladas detectadas via charge_identificator, charge_number e amount.
Observações
Derivado localmente após o sync de transações — não é um recurso Open Finance da instituição.
Agrupa por description + charge_number (total) + data da compra (dia, no fuso de Brasília). A instituição envia a 1ª parcela com o horário real da compra e as seguintes com horário padronizado, por isso o agrupamento usa só a data. charge_identificator ordena as occurrences.
purchased_at é o horário da primeira parcela observada (normalmente a 1ª, com o horário real da compra).
Só considera txs de débito (credit_debit_type = DEBITO) com charge_identificator e charge_number (> 1). Inclui parcelas já lançadas e futuras (bill_post_date = "0001-01-01").
Duas compras na mesma loja, no mesmo dia e com o mesmo número de parcelas são agrupadas como uma só.
Se o consentimento do recurso estiver REJECTED, EXPIRED ou REVOKED (v2 e v3), esta rota retorna HTTP 404: os dados ficam bloqueados até o consentimento receber uma nova autorização — e, após 6 dias sem reaproveitamento, são excluídos. Veja /docs/celcoin/consent-status.
Query Parameters
Field Type Description
cursor string Cursor de paginação (cursor-based). Use o next_cursor da resposta anterior para avançar. 50 itens por página.
Response Fields
Field Type Description
description string Descrição limpa da compra parcelada.
amount number Valor de cada parcela.
totalInstallments integer Total de parcelas (charge_number).
occurrences string[] IDs das transações do cartão, ordenadas por charge_identificator.
