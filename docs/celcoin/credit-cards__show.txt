ownload Bruno Collection
GET/credit-cards/{creditCard}
Obter Cartão
Retorna um cartão de crédito com identification, limits e unbilled_amount em cada limite. Rate-limited — não use para polling.
Observações
Rate limit: 30 requisições/minuto por usuário autenticado (ou IP). Ver /docs/celcoin/rate-limits.
Não faça polling nesta rota. O fluxo ideal é orientado a webhooks.
Ao receber um evento de recurso (ex.: accounts, credit_cards), busque pelo index paginado do consentimento com query_parameters (ex.: GET /consents/{consent}/accounts?{query_parameters}).
Ao receber *.transactions, liste as transações do recurso indicado em resource/resource_id com query_parameters.
Use o show apenas pontualmente — quando precisar do recurso completo (reconciliação, debugging, etc.).
payment_methods está na raiz. O objeto identification é legado — preferir os campos na raiz.
identification e limits podem ser null se ainda não sincronizados.
unbilled_amount (em cada limits[]): soma do brazilian_amount das transações com bill_id null e bill_post_date posterior a bill_closing_date + 1 mês, filtradas pelo identification_number do limite. Null se o cartão não tiver faturas com data de fechamento.

payment_methods[]object
Cartões (virtual, adicional, titular) associados à conta consentida. Também disponível em identification.payment_methods (legado). Só lista plásticos ativos — é obrigatório enquanto o cartão estiver ativo; se já excluído, o envio é opcional. Mesmo quando um cartão sai desta lista, as transações que ele originou continuam trazendo o identification_number correspondente.
Field Type Description
identification_number string Últimos 4 dígitos (PF) ou identificador PJ do cartão.
is_multiple_credit_card boolean Indica se o cartão possui função crédito e débito (múltiplo).
Exemplo
payment_methods[]COPY
{
"identification_number": "4453",
"is_multiple_credit_card": true
}
limits[]object
Array de limites do cartão. Cada item representa uma linha de crédito e inclui unbilled_amount calculado para o identification_number daquele limite.
Field Type Description
consolidation_type string Enum: CreditCardConsolidationType.
credit_line_limit_type string Enum: CreditCardLineLimitType.
identification_number string Número de identificação do cartão.
is_limit_flexible boolean Indica se o limite é flexível.
used_amount object Valor utilizado { amount, currency }.
limit_amount object Limite total { amount, currency }.
available_amount object Limite disponível { amount, currency }.
unbilled_amount object | null Lançamentos em aberto deste identification_number com bill_post_date posterior a bill_closing_date + 1 mês. Formato { amount: number, currency: string }. Null quando o cartão não tem faturas com data de fechamento.
line_name string Enum: CreditCardLineName.
customized_limit_amount object | null Limite customizado { amount, currency }.
line_name_additional_info string | null Informação adicional da linha de crédito.
