GET/credit-fixed-incomes/{creditFixedIncome}/transactions
Transações — Renda Fixa de Crédito
Lista movimentações de um investimento de renda fixa de crédito.
Observações
Quando fromCreatedAt/toCreatedAt e fromUpdatedAt/toUpdatedAt são enviados juntos, a API combina com OR: retorna registros criados OU atualizados na janela (não exige as duas condições ao mesmo tempo).
Query Parameters
Field Type Description
cursor string Cursor de paginação (cursor-based). Use o next_cursor da resposta anterior para avançar. 500 itens por página.
fromCreatedAt string Filtra por created_at a partir desta data (ISO 8601). Opcional.
toCreatedAt string Filtra por created_at até esta data (ISO 8601). Opcional. Deve ser ≥ fromCreatedAt quando ambos forem enviados.
fromUpdatedAt string Filtra por updated_at a partir desta data (ISO 8601). Opcional.
toUpdatedAt string Filtra por updated_at até esta data (ISO 8601). Opcional. Deve ser ≥ fromUpdatedAt quando ambos forem enviados.
fromDate string Filtra por transaction_date a partir desta data (ISO 8601). Opcional.
toDate string Filtra por transaction_date até esta data (ISO 8601). Opcional. Deve ser ≥ fromDate quando ambos forem enviados.

Taxas de Remuneração (Renda Fixa)
Investimentos de renda fixa de crédito (Debêntures, CRI, CRA) expõem campos que descrevem a rentabilidade esperada. A combinação de indexer (enum CreditFixedIncomeIndexer), post_fixed_indexer_percentage e pre_fixed_rate permite interpretar títulos indexados, híbridos e pré-fixados.
Campos
Campo Onde Descrição
indexer remuneration.indexer Indexador de referência contratado na emissão (CDI, IPCA, PRE_FIXADO, etc.).
post_fixed_indexer_percentage remuneration.post_fixed_indexer_percentage Percentual do indexador pós-fixado. Ex.: 100 para “100% do CDI”.
pre_fixed_rate remuneration.pre_fixed_rate Taxa prefixada ou spread adicional sobre o indexador (em % a.a.).
indexer_percentage transactions.indexer_percentage Equivalente ao percentual do indexador na movimentação.
remuneration_transaction_rate transactions.remuneration_transaction_rate Taxa de remuneração registrada na transação.
Exemplos de interpretação
Rentabilidade indexer post_fixed_indexer_percentage pre_fixed_rate
100% CDI + 5% CDI 100 5
IPCA + 10% IPCA 100 10
Pré-Fixado 16,76% PRE_FIXADO — 16.76
12% A.A PRE_FIXADO — 12
O enum RateType (LINEAR / EXPONENCIAL) descreve a forma de cálculo da taxa, não o indexador (CDI, IPCA, etc.).
Campos contratuais em remuneration (raiz) e product.remuneration (legado): indexer, pre_fixed_rate e post_fixed_indexer_percentage.
remuneration.indexer usa o enum CreditFixedIncomeIndexer.
Títulos 100% pré-fixados: remuneration.indexer = PRE_FIXADO, remuneration.post_fixed_indexer_percentage nulo, taxa em remuneration.pre_fixed_rate.
Indexados com spread (ex.: 100% CDI + 5%): percentual em remuneration.post_fixed_indexer_percentage, spread em remuneration.pre_fixed_rate.
