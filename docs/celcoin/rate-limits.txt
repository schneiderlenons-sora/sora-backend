Rate Limits
Limites de requisição aplicados nas rotas da API Celcoin v2 (https://api.polp.com.br/api/v2). Rotas sem throttle explícito não entram nesta lista.
Como funciona
Os limites são por janela de 1 minuto.
Na maioria das rotas, a chave é o usuário autenticado (via API Key) ou o IP se não houver usuário.
Ao exceder o limite, a API responde 429 Too Many Requests.
Prefira webhooks em vez de polling em endpoints de show.
Show de consentimento
Consulta de um consentimento específico. 240 req/minPor usuário autenticado (ou IP)
