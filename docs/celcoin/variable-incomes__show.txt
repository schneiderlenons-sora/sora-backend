# baixado em 2026-08-24

ownload Bruno Collection
GET/variable-incomes/{variableIncome}
Obter — Renda Variável
Retorna um investimento de renda variável com product e balance. Rate-limited — não use para polling.
Observações
Rate limit: 30 requisições/minuto por usuário autenticado (ou IP). Ver /docs/celcoin/rate-limits.
Não faça polling nesta rota. O fluxo ideal é orientado a webhooks.
Ao receber um evento de recurso (ex.: accounts, credit_cards), busque pelo index paginado do consentimento com query_parameters (ex.: GET /consents/{consent}/accounts?{query_parameters}).
Ao receber *.transactions, liste as transações do recurso indicado em resource/resource_id com query_parameters.
Use o show apenas pontualmente — quando precisar do recurso completo (reconciliação, debugging, etc.).
balance é carregado via eager loading e pode ser null se ainda não sincronizado.
Campos de product passam a existir na raiz (versão atual). O objeto product aninhado é legado — preferir os campos na raiz, incluindo remuneration.
product (legado) pode retornar null se o Product Identification ainda não foi sincronizado.
Response Fields
Field Type Description
id string Identificador único do investimento (consolidado por ticker do lote padrão).
consent_id string ID do consentimento vinculado.
issuer_institution_cnpj_number string | null CNPJ da instituição emissora.
isin_code string | null Código ISIN da emissão (ISO 6166).
ticker string | null Código de negociação do ativo em bolsa (ex.: PETR4).
product legado object | null Legado — preferir os campos do produto na raiz. Mantido por compatibilidade.
balance object | null Saldo do investimento. Ver seção Objetos Aninhados → balance.
created_at string Data de criação (ISO 8601).
updated_at string Data de atualização (ISO 8601).
Objetos Aninhados
Estrutura completa dos objetos referenciados nos campos acima. Valores monetários usam o tipo compartilhado { amount, currency }.

Tipo compartilhado para valores monetários em toda a API.
Field Type Description
amount string Valor numérico em formato string (ex.: "1500.00").
currency string Código ISO 4217 (ex.: "BRL").
