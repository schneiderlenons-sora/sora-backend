GET/variable-incomes/{variableIncome}/transactions
Transações — Renda Variável
Lista movimentações de um investimento de renda variável.
Observações
Quando fromCreatedAt/toCreatedAt e fromUpdatedAt/toUpdatedAt são enviados juntos, a API combina com OR: retorna registros criados OU atualizados na janela (não exige as duas condições ao mesmo tempo).
Query Parameters
Field Type Description
cursor string Cursor de paginação (cursor-based). Use o next_cursor da resposta anterior para avançar. 500 itens por página.
fromCreatedAt string Filtra por created_at a partir desta data (ISO 8601). Opcional.
toCreatedAt string Filtra por created_at até esta data (ISO 8601). Opcional. Deve ser ≥ fromCreatedAt quando ambos forem enviados.
fromUpdatedAt string Filtra por updated_at a partir desta data (ISO 8601). Opcional.
toUpdatedAt string Filtra por updated_at até esta data (ISO 8601). Opcional. Deve ser ≥ fromUpdatedAt quando ambos forem enviados.
fromDate string Filtra por transaction_date a partir desta data (ISO 8601). Opcional.
toDate string Filtra por transaction_date até esta data (ISO 8601). Opcional. Deve ser ≥ fromDate quando ambos forem enviados.
Response Fields
Field Type Description
id string Identificador único da transação.
variable_income_id string ID do investimento.
type string Enum: VariableIncomeMovementType.
transaction_type string Enum: VariableIncomeTransactionType.
transaction_type_additional_info string | null Informação adicional.
transaction_date string Data da transação.
price_factor string Fator de preço.
transaction_quantity string Quantidade movimentada.
transaction_unit_price object Preço unitário { amount, currency }.
transaction_value object Valor { amount, currency }.
broker_note_id string | null ID da nota de corretagem.
created_at string Data de criação (ISO 8601).
updated_at string Data de atualização (ISO 8601).
